## Build

The game itself is original work: HTML, CSS, and vanilla JavaScript with no frameworks, no external dependencies, and no network calls. Source-text imagery (nebulae, stations, antennas) is used purely as atmospheric backdrop and is recoloured in CSS to keep a consistent cinematic grade.
